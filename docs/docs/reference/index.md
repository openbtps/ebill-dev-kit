# Reference

Every page here is generated from the code it describes, each time the site is built, so it says what the code does today.

- **API**: every route of `/v1`, from eBillAddress's own OpenAPI document.
- **SDK**: every export of `@ebilladdress/app-sdk`, from its TypeScript.
- **[Webhook topics](./generated/webhook-topics.md)**: each topic, the scope it needs and what its `data` holds; and every scope.
- **[CLI](./generated/cli.md)**: each `ebill` command, from its own help.

The [app contract](https://github.com/openbtps/ebill-dev-kit/blob/main/CONTRACT.md) describes everything between an app and
eBillAddress in one page: the install flow, the API, webhooks, scopes and the app files.
